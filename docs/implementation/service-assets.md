# Laundry service assets

The current catalog contains four original SVG illustrations and their
native-safe PNG siblings under `assets/services/`:

- `wash-and-fold.svg`: garments beside a washing-machine drum.
- `wash-and-iron.svg`: an iron on an ironing board.
- `steam-press.svg`: a steam press above a shirt.
- `dry-clean.svg`: a blazer on a hanger.

Each SVG has a 240×160 viewBox and accessible title/description. Artwork uses
cream, ink and teal. No remote fonts, scripts, trackers or third-party images
are embedded. Native apps prefer the PNG siblings because React Native Image
has no reliable SVG support on Android/iOS.

Authorship, palette, licensing and PNG derivation are recorded in
`assets/services/manifest.json`. Original SVG code was created by the Freebuff
coding agent for Laundry. The current asset set has no separate brand-mark file;
older verification reports describe a previous asset set, not this manifest.
